# ☁️ AWS Builder Loft LEGO Models

Welcome to the digital construction site.

This repository contains the **BrickLink Studio source files, iterations, and supporting assets** for the LEGO models being developed for the AWS Builder Loft project.

The models are designed to turn AWS developer culture, inside jokes, and Builder Loft architecture into physical LEGO scenes.

## 🧱 What's Being Built?

The project consists of **8 LEGO models**:

### 👨‍💻 Developer Dioramas × 4

Scenes inspired by the everyday experiences, problems, and questionable decisions of software developers.

Expect things like:

* Debugging
* Deployments
* Broken code
* Developer folklore
* AWS in-jokes
* And situations that probably seemed like a good idea five minutes before production

### 🏢 Builder Loft Locations × 4

Models inspired by AWS Builder Loft spaces around the world, incorporating architectural details and the **animal mascot associated with each location**.

Current locations include:

* 🇺🇸 San Francisco
* 🇩🇪 Berlin
* 🇮🇳 Hyderabad
* 🇧🇷 São Paulo

## 🛠️ Design Process

The models are developed primarily in **BrickLink Studio**, with designs evolving through multiple iterations before becoming physical builds.

The repository provides a way to track that process rather than having:

> `FINAL.io`
> `FINAL2.io`
> `FINAL_USE_THIS_ONE.io`
> `FINAL_USE_THIS_ONE_REAL.io`
> `FINAL_USE_THIS_ONE_REAL_v2.io`

Git seemed like the safer option.

## 🔄 Version Control

Designs are committed throughout development so that major changes can be tracked and previous iterations can be recovered.

This makes it possible to:

* Experiment with different designs
* Compare iterations
* Revert questionable decisions
* Preserve earlier concepts
* Keep the digital model synchronized with the physical build

In other words:

**Git is the LEGO instruction booklet for things that haven't been built yet.**

## 📂 Repository Structure

The exact structure may evolve as the project develops, but each model is generally kept with its associated Studio files and supporting assets.

Generated files that BrickLink Studio creates automatically are excluded from version control where appropriate.
